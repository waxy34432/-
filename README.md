# Telegram-бот: выбор города и округа/района + админ-панель

## Что умеет
- `/start` — показывает приветствие (текст задаётся в коде/через админку) и кнопку **«Выбрать город»**.
- При нажатии — 4 кнопки городов: Москва, Санкт-Петербург, Нижний Новгород, Красноярск.
- При нажатии на город — кнопки его административных округов/районов (количество своё для каждого города, подтягивается из базы).
- `/admin` — админ-панель (видна только тем, чей Telegram ID указан в `config.py`):
  - изменить текст приветствия;
  - добавить/переименовать/удалить город;
  - добавить/переименовать/удалить округ/район у любого города.

Все данные (приветствие, города, округа) хранятся в SQLite-файле `bot.db`, который создаётся автоматически при первом запуске и заполняется стартовым набором округов/районов. Дальше всё меняется через `/admin`, без правки кода.

## Установка

1. Установи Python 3.10+.
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Получи токен бота у [@BotFather](https://t.me/BotFather) и вставь его в `config.py`:
   ```python
   BOT_TOKEN = "твой_токен"
   ```
4. Узнай свой Telegram ID (например, у [@userinfobot](https://t.me/userinfobot)) и добавь его в `config.py`:
   ```python
   ADMIN_IDS = [123456789]
   ```
5. При желании поменяй текст приветствия по умолчанию в `config.py` — переменная `DEFAULT_GREETING`. Он используется только при первом запуске (пока в базе ещё ничего нет); дальше его удобнее менять командой `/admin`.

## Запуск

```bash
python bot.py
```

## Как добавить ещё один город или изменить количество округов
Не нужно лезть в код — всё делается через `/admin` → **Управление городами**:
- «➕ Добавить город» — добавит новый город с нулём округов;
- открой карточку города → «📍 Округа/районы» → «➕ Добавить округ/район» — добавит сколько угодно кнопок для этого города;
- там же можно переименовывать и удалять и города, и округа/районы.
